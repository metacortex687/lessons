Добавлен итератор над множеством для удобного перебора всех элементов в цикле для реализации объединения, пересечения, разницы и определения вхождения подмножества в другое множество.

Взята хэш-таблица из задания 7. В которую также добавлен итератор перебора элементов.

Множество мутабельное. Если убрать элементы вставки и удаления, то оно станет имутабельным, но тогда нужен конструктор, который создает непустое множество.

Передаваемый тип должен преобразовываться в строку. Это будет, если множество состоит из элементов примитивных типов, например строка или число. В случае произвольного типа, он должен быть произвольным от:

```
abstract class Hashable {
    abstract hash(): string;
}
```
