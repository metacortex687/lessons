В эталонном решении для Python предполагается, что у типов есть атрибут value. У меня нет такого предположения, поэтому решение похоже на решение для Java.

Сигнатура метода. Передаю тип, к которому надо привести, и далее выражение участвует в проверке типов.
```
T = TypeVar("T")
def assignment_attempt(target_type: type[T], source) -> T | Void:
```

При этом Void в эталонном решении кажется более удачным названием для пустого типа, чем CNone у меня изначально.

Проверка типов с помощью mypy выполнена для тестовых примеров в блоке `if __name__ == '__main__':` .

Можно было бы мне использовать в решении `getType` из базового класса `General`, следуя принципу повторного использования кода.
