Разберу варианты наследования.

Под приватным методом буду подразумевать метод с подчеркиванием. Под скрытым можно понимать недоступный метод, тоесть как приватный метод, так и метод, который возвращает `raise NotImplementedError`.

1. Метод публичен в родительском классе А и публичен в его потомке B. 
   Да.
    
3. Метод публичен в родительском классе А и скрыт в его потомке B. 
   Переопределить метод, вызывая исключение `NotImplementedError`. Ответил, что нельзя понизить видимость, хотя можно понимать под скрыт, то, что он недоступен к использованию. Проверка корректности типов с помощью `mypy`, `ty`, `Pyrefly`, не обработает корректно этот вариант с `raise NotImplementedError`, считая метод доступным к использованию. А например `CrossHair`  обработает.
   
```python
class A:
   def method(self) -> int:
      return 42
   
class B(A):
   def method(self) -> int:
      raise NotImplementedError

B().method()  # mypy, Pyrefly, ty принимают проверку типов, CrossHair нет
```
    
3. Метод скрыт в родительском классе А и публичен в его потомке B. 
   В python по факту утиная типизация, тоесть тип определяется доступными методами. Сигнатура метода определяется именем и входными выходными параметрами. Публичность и приватность подразумевает разные названия методов в python, у приватного метода есть подчеркивание. Это причина, почему формально строго невозможно изменение видимости с приватного на публичный. Хотя и можно обернуть в публичный метод, который вызывает приватный. Но формально у него будет другое имя.
    
4. Метод скрыт в родительском классе А и скрыт в его потомке B. Да, как и для публичных методов, это происходит по умолчанию при наследовании. Он доступен внутри класса потомка как приватный.
    

Есть еще вариант, когда метод скрыт в родительском классе и его нет в классе потомке даже как скрытого. Необходимо бывает при множественном наследовании, например, чтобы была разрешимость в типах. В этом случае помогает двойное подчёркивание `__`, как перед приватными методами, так и перед приватными переменными.
