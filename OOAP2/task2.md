а) Специализация класса-родителя. Происходит сужение типа, экземпляров множества объектов, задаваемых подклассом, не больше, чем экземпляров объектов в множестве, задаваемых суперклассом.

```python
class Animal:
	pass
	
class Cat(Animal):
	pass
```

б) Расширение класса-родителя.

Формально можно от класса Cat унаследовать Animal. Но это будет по аналогии с «дыркой в языке», но только для кода.

Если так сделать, то любой объект, экземпляр класса Animal, должен быть и экземпляром класса Cat. Что неверно. В случае если кроме Cat нет других объектов, то и не надо создавать класс Animal, это будет избыточная функциональность.

в) В наследовании применяется как расширение класса-родителя, так и специализация класса-родителя.

Циклическое наследование нельзя сделать.
