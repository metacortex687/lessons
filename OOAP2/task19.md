**Наследование с сужением:**

Водный транспорт транспорт <- морской транспорт 
Водный транспорт транспорт <- пресноводный транспорт

Сотрудник предприятия <- юрист, маркетолог, программист. 
Рассуждения в этом случае такие, что в небольшой компании сотрудники занимаются сразу многими обязанностями, но по мере увеличения компании обязанности специализируются, значит это сужение.

Программист <- Разработчик, Системный Администратор. 
И здесь сужение должностных обязанностей.

А если рассматривать с точки зрения навыков и взять за базовый тип физ. лицо или человека, то было бы расширение за счет навыков.

**Наследование с расширением:**

«Автоматизированное рабочее место» расширения для «рабочее место». 
Доступна новая операция, запуск ПО.

«Документ с цифровой подписью» является расширением для «Документ».

«База данных пользователя» является расширением для «База данных». 
Есть методы для получения информации о пользователе базы данных.


`MutableObject` расширяет `ImmutableObject`, так как добавлены новые методы для его изменения. 
Хотя функцию хэша для MutableObject надо «испортить», а лучше спрятать, должна возвращать пустой объект, тесть это уже сужение. Значит это смешанный случай.
